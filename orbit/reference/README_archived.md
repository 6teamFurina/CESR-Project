# Archived orbit reference data

This directory-level description applies to the unscoped reference files
retained from the original CESR export. They are historical inputs for explicit
reproduction or Bmad-versus-SciBmad comparison, not latest-ring defaults.

- `closed_orbit_response_6x119.csv` is the legacy fixed-dimension response
  cache.
- `cesr_bmad_compatible.bmad` and its digested file are legacy Bmad reference
  lattice artifacts.

The maintained latest-ring cache is documented separately in
[`latest_cesr/README.md`](latest_cesr/README.md) and must be read through its
labeled metadata contract.
