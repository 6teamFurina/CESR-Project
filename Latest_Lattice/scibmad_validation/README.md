# SciBmad validation results

This directory contains generated SciBmad validation reports, comparison CSVs,
and captured load logs for `../latest_cesr_scibmad_repaired.jl`. Reproduction
and diagnostic programs live in `../support_codes/`; Bmad inputs and reference
outputs live in `../bmad_reference/`.

The quantified curved-DQX girder-pitch and photon-mirror limitations remain
documented in the validation summaries and conversion report.
