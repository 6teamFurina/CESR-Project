# Bmad reference and load outputs

This directory contains Bmad/Tao-derived material used only for conversion,
reference validation, and cross-code discrepancy diagnosis.

- `inventory/` contains branch, element, control-lord, and relation inventories.
- `branch0/`, `control_tracking/`, and `girder/` contain numerical Bmad reference
  outputs consumed by the SciBmad validation programs.
- `raw_exports/` contains Tao-generated SciBmad exports and writer logs.
- `load_results/` contains digested Bmad load artifacts. The
  `load_results/archive_original/lat.bmad.digested361` file is the one unique
  item preserved from the former `Archive/` directory; the duplicate lattice
  sources were removed after byte-for-byte comparison. The
  `load_results/verification_20260821/` artifact was generated by the
  post-reorganization `Ubuntu-Bmad` load check and moved out of the lattice
  directory afterward.

No cryptographic hash validation is used in this project.
