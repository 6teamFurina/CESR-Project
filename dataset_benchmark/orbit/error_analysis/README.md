# Orbit response error analysis

This directory contains the 600-trial normalized-radius sweep used to test the
validity range of the first-order SciBmad orbit response approximation.

## Layout

- `response_rho_sweep_600/combined/`: merged trial-level data, per-radius
  summaries, scaling analysis, and run metadata.
- `response_rho_sweep_600/chunks/`: the five original parallel calculation
  chunks, including their logs and metadata.
- `response_rho_sweep_600/figures/`: publication-style PNG and SVG figures.

The figures are the optimized versions produced in Codex task
`019fc8a1-c940-7c83-97b7-4861ec542439`.
