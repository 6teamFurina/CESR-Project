# Thick-element Hessian sourcing of the detector quadratic response

This experiment attributes either the horizontal or vertical second-order
detector response to the local Hessian source generated by each complete
SciBmad lattice element. It does not replace a finite-length sextupole by a
midpoint thin kick. The default `--output-plane=x` preserves the original
horizontal calculation; `--output-plane=y` selects the vertical detector
coordinate while reusing the same corrector directions and normalization.

For every fixed horizontal/vertical corrector-direction pair, the program:

1. implicitly differentiates the RF-on periodic closed orbit;
2. propagates the first and second derivatives through every complete element;
3. isolates the new local second-order source at element `j` as
   `g_j = S_exit - A_j*S_entrance`;
4. propagates that six-dimensional source through the periodic ring to all 99
   detectors; and
5. compares both the all-element and active-normal-sextupole reconstructions
   with the adopted GTPSA detector vectors.

The all-element reconstruction is the numerical closure check for the source
decomposition. The sextupole-only residual measures the part of the full
quadratic response not generated locally by the 76 active normal sextupole
elements under this element-boundary convention.

Run from the `CESR Project` root:

```powershell
julia --project=. dataset_benchmark/orbit/error_analysis/thick_element_sextupole_sourcing/run_thick_element_sourcing.jl
python dataset_benchmark/orbit/error_analysis/thick_element_sextupole_sourcing/analyze_thick_element_sourcing.py
```

Use `--trials=3 --output-dir=.../smoke` for a quick integration test.

The default command writes the maintained horizontal result to
[`horizontal_results/`](horizontal_results/). The maintained vertical run is:

```powershell
julia --project=. dataset_benchmark/orbit/error_analysis/thick_element_sextupole_sourcing/run_thick_element_sourcing.jl --trials=100 --seed=20260804 --base-kick-rad=5e-6 --output-plane=y --output-dir=dataset_benchmark/orbit/error_analysis/thick_element_sextupole_sourcing/vertical_results
python dataset_benchmark/orbit/error_analysis/thick_element_sextupole_sourcing/analyze_thick_element_sourcing.py dataset_benchmark/orbit/error_analysis/thick_element_sextupole_sourcing/vertical_results
```

Its generated report is
[`vertical_results/RESULTS.md`](vertical_results/RESULTS.md). The vertical
all-on target is retained as `Q_hh,y + Q_hv,y + Q_vv,y`; the three blocks are
not set to zero from symmetry assumptions, so their measured shares also act
as a numerical parity check.
