# Archived response-radius sweep

The unscoped `chunks/`, `combined/`, and `figures/` artifacts in this directory
belong to the original CESR response-radius study. They are retained for
historical reproduction and manuscript provenance only; their fixed control,
detector, and output conventions must not be treated as latest-ring results.

The maintained latest-ring smoke and future production outputs are documented
under [`latest_cesr/README.md`](latest_cesr/README.md). The latest production
grid remains `not_run` until a complete ring-scoped run is generated and its
metadata records the discovered registries and solver provenance.
